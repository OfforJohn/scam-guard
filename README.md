# Scam Guard

Protection from Scams & Fraud - Get warnings, protection and peace of mind with Scam Guard. Stay safe from scam calls, fraud, and dark web data leaks with AI-powered triple protection.

## Features

- AI Triple-Lock Protection
- Real-time device protection
- Dark web and social media monitoring
- Call labelling and scam detection
- Password manager integration

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Setup

1. Clone the repository
2. Open `index.html` in a web browser
3. Or run a local server: `python -m http.server 8000`
